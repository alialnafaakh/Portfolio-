# 🚀 Professional Developer Portfolio

A high-performance, responsive portfolio website built with **Next.js** and **TypeScript**. This project showcases my journey as a developer, featuring my latest projects, technical skills, and professional experience.

![Portfolio Preview](https://portfolio-70vlbrd9u-alis-projects-f89bfee1.vercel.app/api/og) ## 🌐 Live Demo
You can view the live site here: [View Portfolio](https://portfolio-70vlbrd9u-alis-projects-f89bfee1.vercel.app/)

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Static Typing for robust code)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Components:** Radix UI / Shadcn UI

## ✨ Key Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Server-Side Rendering (SSR):** Fast loading times and SEO friendly.
- **Dynamic Projects Section:** Showcasing web applications with live links and source code.
- **Type Safety:** Built with TypeScript to ensure high code quality and maintainability.
- **Dark/Light Mode:** Seamless theme switching for better user experience.
